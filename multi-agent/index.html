Multi-Agent Research Assistant

Ask one question. A Planner splits it into sub-tasks, Researchers work on them in parallel, a Fact-checker cross-checks every claim, a Writer drafts the report, and a Critic sends it back until each point is backed by a checked claim.

02idle

Researchers

One per sub-task, in parallel. Each returns claims with a confidence level.

03idle

Fact-checker

Merges duplicates and marks each claim consistent, uncertain or conflicting.

04idle

Writes the report and cites a claim id after every fact.

Critic

Checks citations and coverage. Sends the draft back if something is off.

This web demo runs every agent on the model's own knowledge, so it has no live web search and no source links. The full Python version (LangGraph, FastAPI, Streamlit) adds Search and Reader agents that pull real pages through Tavily, and only marks a claim verified when two separate websites agree.
