Desktop-only commands

The Python desktop version of Ultron also controls the computer itself. These need that version, since a web page can't reach your system:

  • Open and close installed apps
  • Screenshots
  • Volume and brightness
  • Lock, restart, shut down
  • Type text and press keys
  • WhatsApp and email messages
  • CPU, memory and battery status
  • Wake word and standby
